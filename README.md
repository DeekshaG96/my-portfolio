# My Portfolio 🌌

Welcome to my personal portfolio! This is a visually stunning, Cyber-Noir themed web experience designed to showcase my identity as a security-conscious AI innovator.

## 🚀 Features

- **Cyber-Noir Aesthetics:** A futuristic color palette featuring Neon Cyan and Magenta.
- **Glassmorphism UI:** Sleek, modern interfaces with translucent, frosted-glass effects.
- **Dynamic Animations:** Scroll-triggered fade-ins and dynamic typing animations powered by Motion.
- **AI Integration:** Seamlessly integrated with Google's Gemini AI.
- **Responsive Design:** Optimized for all devices using Tailwind CSS.

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite, Tailwind CSS 4
- **Animations:** Motion
- **Icons:** Lucide React
